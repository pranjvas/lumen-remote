# YouTube

- Playing a video: play_youtube with the 11-character id plays it at once (DIAL v=<id>).
- The app declares launch_search_q.link "#?q=" and launch_search_v.link "#?v=" (YouTube TV URL fragments).
- In-app search uses YouTube's own on-screen keyboard; voice search is not available from Lumen.
